# لوحة تحكم ChatPro — إعداد عربي

لوحة ويب مستقلة تستخدم Firebase Authentication وتستدعي عمليات الإدارة عبر Cloud Functions. الواجهة لا تمنح صلاحية المدير بنفسها؛ كل عمليات الإدارة تتحقق من custom claim `admin: true` على الخادم.

## ميزات اللوحة
- إحصائيات المستخدمين والغرف والمحادثات والرسائل والبلاغات والحسابات المحظورة.
- البحث ضمن المستخدمين وعرض الحالة وآخر ظهور، وحظر الحساب أو إعادة تفعيله.
- عرض الغرف وحذف الغرفة مع رسائلها وملفاتها المخزنة.
- مراجعة البلاغات وتحديدها تمت معالجتها أو رفضها.
- إرسال إشعار FCM عام للمستخدمين ذوي الرموز المسجلة.
- لا تعرض محتوى المحادثات الخاصة.

## الإعداد والنشر
1. افتح Firebase Console وأنشئ تطبيق Web في نفس مشروع Firebase الذي يستخدمه ChatPro.
2. انسخ قيم إعدادات التطبيق إلى `firebase-config.js` في هذا المجلد. لا تترك القيم `YOUR_...`.
3. ثبّت Firebase CLI إن لم يكن مثبتاً، ثم سجّل الدخول: `firebase login`.
4. من مجلد المشروع الرئيسي نفّذ `firebase use --add` واختر مشروع Firebase الصحيح.
5. امنح حسابك الإداري صلاحية في Firebase Authentication وأنشئ له حساباً ببريد مفعّل داخل ChatPro.
6. أنشئ مفتاح Service Account من Google Cloud/Firebase IAM وفق الصلاحيات المناسبة، واحفظه خارج مجلد المشروع. اضبط متغير البيئة `GOOGLE_APPLICATION_CREDENTIALS` ليشير إلى ملف المفتاح.
7. من مجلد `functions` ثبّت الحزم: `npm install`.
8. من مجلد `functions` نفّذ: `node set_admin.js YOUR_FIREBASE_AUTH_UID`.
9. انشر القواعد والوظائف والاستضافة من جذر المشروع: `firebase deploy --only firestore:rules,storage,functions,hosting`.
10. افتح رابط Firebase Hosting، وسجّل الدخول بالبريد وكلمة المرور للحساب الإداري. إذا كنت مسجلاً مسبقاً، سجّل الخروج ثم الدخول حتى تتحدث صلاحية `admin`.

## تنبيهات أمان مهمة
- لا ترفع ملف Service Account إلى GitHub أو ترسله لأي شخص. احذفه/دوّر المفتاح إذا انكشف.
- `firebase-config.js` يحوي إعدادات تطبيق الويب العامة وليس مفتاح Service Account؛ مع ذلك يجب تقييد Authorized domains في Firebase Authentication.
- صلاحية الإدارة في custom claims لا تُمنح من واجهة المتصفح. استخدم `set_admin.js` فقط من بيئة موثوقة.
- حظر الحساب يوقف تسجيل الدخول ويضبط علامة `isBanned` على مستند المستخدم. قد تحتاج جلسة المستخدم الحالية إلى إعادة التحقق/تحديث الرمز حتى تنعكس كل التغييرات فوراً.
- حذف الغرفة يحذف وثيقة الغرفة والمحادثة ورسائلها وملفات `chat_uploads/<roomId>/`؛ لا يمكن ضمان إزالة النسخ الموجودة في أي نسخ احتياطية خارج Firestore/Storage.
- الإحصائيات تستخدم Firestore count aggregation؛ قد تتطلب فهرسة/دعم الخدمة وخطة فوترة مناسبة حسب إعداد Firebase.
- اختبر على مشروع Firebase تجريبي أولاً، وراجع سجلات Functions وقواعد الأمان قبل استخدام بيانات حقيقية.
